## 🏏 ICC Cricket World Cup 2023 Analysis (Crio.do)

## 📌 Project Overview
This project presents a comprehensive analysis of the **ICC Men's Cricket World Cup 2023** using **Python** for data manipulation and visualization.  
The goal of this project is to extract meaningful insights from match, player, batting, bowling, and venue datasets to understand tournament patterns and performance trends.

This analysis highlights **top performers**, **team consistency**, **venue impact**, and **match-winning factors**.

---

## 🎯 Objectives
The project aims to answer the following key questions:

- Who were the top scorers and top wicket-takers in each match?
- Which venues were best for batting first vs chasing?
- Which players dominated the Player of the Match awards?
- What match outcome patterns were observed (wins by runs vs wickets)?
- Which teams performed consistently throughout the tournament?

---

## 📂 Dataset Used
The analysis was performed using the following datasets:

- `World-Cup-2023-Schedule.csv`
- Batting summary dataset
- Bowling summary dataset
- Match results dataset
- Player information dataset

---

## 🔍 Key Analysis Performed

### ✅ Data Preparation
- Loaded and inspected the datasets
- Handled missing values and inconsistent records
- Removed duplicates
- Standardized column names and formats
- Converted required columns into correct data types

### ✅ Exploratory Data Analysis (EDA)
- Identified best scorer and best bowler in each match
- Stadium-wise performance evaluation
- Player of the Match (MoM) distribution analysis
- Match outcome trend analysis (won by runs vs wickets)

### ✅ Visualization & Reporting
- Used bar charts and summary tables to highlight top performers
- Venue-based scoring patterns and match-winning trends
- Team-wise comparison for batting and bowling dominance

---

## 📊 Results & Insights

### 🏏 Top Performers
- **Daryl Mitchell** was the best scorer in matches **3 times**
- **Adam Zampa** was the best bowler in matches **5 times**

### 🏟 Venue Insights
- **Wankhede Stadium** was identified as the best venue to **bat first**
- **Ekana Stadium** was identified as the best venue for **bowling first**

### ⭐ Player of the Match (MoM)
- **Travis Head** and **Mohammad Shami** won the most MoM awards (**3 each**)
- MoM awards were dominated by:
  - **All-rounders** (15 awards)
  - **Batsmen** (15 awards)

### 🏆 Team Performance Trends
- Australia’s all-rounders won **6 MoM awards**
- India’s batsmen won **5 MoM awards**
- India won:
  - **5 matches by runs**
  - **5 matches by wickets**
- Australia won:
  - **4 matches by runs**
  - **5 matches by wickets**
